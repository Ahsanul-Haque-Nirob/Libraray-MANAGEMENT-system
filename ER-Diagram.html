Database library_management (MySQL). PK = primary key, FK = foreign key, UK = unique.

Books ↔ Members is a many-to-many relationship resolved by the BORROW_RECORDS table.

Business rules

  • A user who logs in is matched to a member by email. If no member has that email, a member row is created for them.
  • A loan lasts 14 days. Loans still out after due_date become overdue. A late return is fined 5 per day.
  • Borrowing decrements books.available_copies; returning increments it (never above total_copies).
  • A member can hold only one active loan of the same book, and must have status = active to borrow.
  • Admin is the user with email admin@library.com. Only the admin can add, edit or delete records.
  • Laravel's own tables (migrations, sessions, password_reset_tokens) are left out because they don't hold library data.
